`tmux-window-manager` is a TPM plugin and self-contained Go binary. Press
`prefix + w` to search every tmux window, inspect pane previews, and switch
without leaving the keyboard. Coding agents can report whether they are working
or waiting for you, without polling pane text.

## Runtime requirements

The plugin supports macOS and Linux. It requires tmux 3.2 or newer, `fzf`, and
Go 1.25 or newer for the build-on-install step. At runtime, the only external
commands used by the picker are `tmux` and `fzf`.
